# 🎰 Pokémon Slot Machine Game

A **fun and interactive slot machine game** inspired by Pokémon, built using **Pixi.js (ES6)**.  
Spin the reels, match Pokémon, and see if you can hit the jackpot! ⚡

## ✨ Features

- 🎨 **5x3 Slot Grid** — Classic slot layout with vibrant Pokémon symbols  
- ⚡ **Smooth Animations** — Powered by **Pixi.js** for GPU-accelerated rendering  
- 🧠 **Modular ES6 Code** — Organized and easy to extend  
- 🔊 **Sound Effects** — Realistic spin and win sounds  
- 💰 **Winning Logic** — Calculates line wins and displays messages dynamically  
- 📱 **Responsive Design** — Scales to different screen sizes
